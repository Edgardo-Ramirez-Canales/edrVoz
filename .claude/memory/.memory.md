# Project Memory — EDR Voz

## Idioma
Siempre responder en español en este proyecto, sin excepciones.

## Reglas de trabajo
- No modificar `hotkey.rs` — está obsoleto, reemplazado por `tauri-plugin-global-shortcut`. Será eliminado en una limpieza futura.
- El hotkey definitivo es `Ctrl+Shift+J` — ignorar cualquier referencia a `Ctrl+Win+D` en archivos viejos.
- Este proyecto es 100% Windows nativo — no sugerir soluciones WSL, cross-platform ni Linux/Mac.
- El directorio definitivo del proyecto es `C:\edrVoz`.

## Convención de commits
Formato obligatorio: `tipo: descripción en español`

| Tipo       | Cuándo usarlo                        |
|------------|--------------------------------------|
| `feat:`    | nueva funcionalidad                  |
| `fix:`     | corrección de bug                    |
| `docs:`    | cambios en documentación             |
| `refactor:`| reestructuración sin cambio de lógica|
| `chore:`   | tareas de mantenimiento              |
| `test:`    | agregar o modificar pruebas          |

## Ramas
- Desarrollo activo: `edr-voz-desarrollo`
- Nunca hacer push directo a `master`
- Features nuevas: rama `feature/nombre` que sale de `edr-voz-desarrollo`

## Archivos locales (no están en git)
- `INSTRUCCIONES.md` — guía de configuración y compilación para el desarrollador
- `IMPLEMENTATION_STATUS.md` — estado detallado de implementación
- `.claude/memory/` — esta carpeta con la memoria del proyecto

# Git Workflow Rules

- Feature branches siempre: `feature/`, `fix/`, `hotfix/`, `chore/` — nunca trabajar en main.
- Commits atómicos: un commit = un cambio lógico, mensaje en tiempo presente.
- PR obligatorio para mergear a main — al menos un revisor.
- Nunca force push a main.

# Debugging Rules

- Revisar logs y stack trace completo antes de tocar cualquier código.
- Reproducir el error de forma consistente antes de intentar corregirlo.
- Identificar causa raíz, no el síntoma — no parchear sin entender por qué falló.
- Verificar cambios recientes en git (`git log`, `git diff`) antes de asumir causas.

# DevOps Rules

- CI/CD automatizado: build → test → deploy, en ese orden obligatorio.
- Variables de configuración separadas por ambiente: dev, staging, prod.
- Plan de rollback definido antes de cada deploy a producción.
- Smoke tests post-deploy antes de cerrar el ciclo de deploy.

> Gestión de ambientes y variables: `00_AI_CORE/GLOBAL_STANDARDS/environments.md`
